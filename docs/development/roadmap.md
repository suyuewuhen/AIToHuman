# 产品与开发路线图

路线图以里程碑和退出条件为主，不先承诺未经团队评估的具体日期。

## M0：产品与工程基线（进行中）

交付：

- 产品愿景、MVP PRD、用户故事和风险边界。
- 系统架构、领域状态机和 API 约定。
- [x] Vue 与 .NET 项目骨架。
- [x] PostgreSQL、Redis、MinIO 的本地开发环境定义。
- [x] CI、格式和测试基线。
- [ ] 秘密扫描与依赖更新自动化。

退出条件：团队确认首发城市、任务分类、AI 建议价冷启动方式和身份/支付策略；开发环境可复现。

## M1：AI 建单闭环

交付：

- 注册、登录和基础账户。
- AI 对话、缺失字段澄清和结构化草稿。
- 草稿编辑、风险规则、确认和任务发布。
- 管理员查看风险决策和下架任务。

退出条件：测试用户能稳定完成对话到发布；禁止任务测试集达到上线要求；AI 失败有明确降级路径。

## M2：任务大厅与订单

交付：

- 服务者资料和服务区域。
- 大厅列表、筛选和任务详情。
- AI 建议价、用户设定/提高悬赏、报名、撤回、选择报名者和订单创建。
- 后端状态机、审计和基础通知。

退出条件：并发选单无重复订单；跨用户和跨角色越权测试通过；公开数据不泄露精确位置。

## M3：履约与信任

交付：

- 订单消息和 SignalR 更新。
- 文件上传、扫描、凭证关联和验收。
- 取消、超时、争议、双向评价盲期/公开和运营处理。
- 完整可观测性、备份和恢复演练。

退出条件：核心端到端场景和异常场景通过；对象权限、安全日志与运营处置流程通过评审。

## M4：封闭试点

交付：

- 一个城市、有限类别、邀请制用户与服务者。
- 运营看板、反馈入口和人工兜底流程。
- 身份验证及通知渠道的受控接入。

退出条件：获得草稿转化、报名时间、建议价采纳率、用户加价率、完成率、争议率和安全事件的可信基线；决定是否进入真实交易试点。

## M5：交易与规模化准备

前置条件：法律和支付方案已评审。

交付候选：

- 合规支付、托管/分账、退款、账本和对账。
- 欺诈检测、信用体系、地图与地理围栏。
- 更丰富的通知和移动端体验。
- 依据真实容量数据进行性能优化或模块拆分。
