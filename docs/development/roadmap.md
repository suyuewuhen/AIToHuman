交付：

- ✅ 系统架构、领域状态机和 API 约定。
- ✅ Vue 与 .NET 项目骨架。

- ⚠️ CI、格式和测试基线：`.github/workflows/ci.yml` 已执行后端 `restore/build/test` 和前端 `npm ci/build`，并有 `.editorconfig` 与 6 个领域单元测试；尚无 Lint、Markdown 检查、OpenAPI 兼容性检查和技术文档生成。
- ⛔ 秘密扫描与依赖更新自动化。

遗留项：

- ⚠️ 数据库结构存在 4 个 EF Core Migration（`AddUsers`、`AddOrders`、`AddOrderEvidence`、`AddReviews`），但 API 启动仍使用 `EnsureCreated()` 加幂等 SQL 建表，两者并存需要收敛为 Migration 单一来源。

退出条件：团队确认首发城市、任务分类、AI 建议价冷启动方式和身份/支付策略；开发环境可复现。开发环境可复现已基本达成，产品决策项仍未确认。

## M1：AI 建单闭环（核心已实现）

交付：

- ✅ 注册、登录和基础账户，含密码哈希、JWT 和 `owner`/`worker` 角色切换。
- ⚠️ AI 对话、缺失字段澄清和结构化草稿：多轮澄清、SSE 流式输出和结构化 `plan` 已实现；对话不持久化，刷新即丢失，也没有 Conversation 实体。
- ⚠️ 草稿编辑、风险规则、确认和任务发布：草稿区在信息完整前保持锁定，用户可调整悬赏、预览草稿后确认发布；但标题、描述、截止时间和验收标准不可在页面编辑（只有悬赏能按 +5 递增），风险规则完全缺失，任务不会被拦截或转人工审核。
- ⛔ 管理员查看风险决策和下架任务。

退出条件：测试用户能稳定完成对话到发布；禁止任务测试集达到上线要求；AI 失败有明确降级路径。多轮对话和发布已可用，超时（120 秒无数据）和流内 `error` 事件提供基本降级；禁止任务测试集和风险拦截完全缺失。

## M2：任务大厅与订单（核心已实现）

交付：

- ⛔ 服务者资料和服务区域：没有 `WorkerProfile`，报名不校验账户状态、类别或区域；报名接口也不返回服务者信用，需求方选人时看不到服务者评价摘要，双向选择目前只有单向可见。
- ⚠️ 大厅列表、筛选和任务详情：列表与公开详情已实现，只返回区域、悬赏、验收标准和报名数；分类、时间、距离筛选和分页尚未实现（当前一次返回全部已发布任务）。
- ⚠️ AI 建议价、用户设定/提高悬赏、报名、撤回、选择报名者和订单创建：建议价（本地规则）、悬赏设定与分配前加价、报名、选择报名者和订单创建已实现；撤回和报名有效期未实现。
- ⚠️ 后端状态机、审计和基础通知：任务与订单状态机已实现；审计日志缺失；通知只有选人后的 SignalR `OrderCreated`，进程内 fire-and-forget，无持久化与重试。

退出条件：并发选单无重复订单；跨用户和跨角色越权测试通过；公开数据不泄露精确位置。公开数据不泄露精确位置已满足（当前尚未采集精确位置）；并发选单没有并发令牌或数据库事务保证，越权仅有部分领域单元测试覆盖。

## M3：履约与信任（部分实现）

交付：

- ⚠️ 订单消息和 SignalR 更新：只有选人后的 `OrderCreated` 推送，没有订单内消息、未读数或状态变更事件。
- ⚠️ 文件上传、扫描、凭证关联和验收：验收与驳回已实现（驳回必须填原因）；文件上传、扫描和凭证关联未实现，服务者只能提交文本说明。
- ⚠️ 取消、超时、争议、双向评价盲期/公开和运营处理：评价盲期与公开规则（双方提交或 7 天后）已实现；取消、超时和争议未实现，运营处理缺失。
- ⛔ 完整可观测性、备份和恢复演练。

退出条件：核心端到端场景和异常场景通过；对象权限、安全日志与运营处置流程通过评审。当前只覆盖正常履约路径，异常场景和运营流程都未开始。
